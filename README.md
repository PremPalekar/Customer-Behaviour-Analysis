# Customer-Behaviour-Analysis | Python, SQL & Power BI

An end-to-end data analytics project focused on understanding customer purchasing behaviour, subscription patterns, discount usage, product ratings, and sales performance. This project combines Python-based data preparation, PostgreSQL database integration, SQL business analysis, and an interactive Power BI dashboard.

## Dashboard Preview

![Customer Behaviour Dashboard](images/customer_behaviour_analysis(1).png)

## Project Overview
-
The objective of this project is to analyse customer shopping data, answer business-related questions using SQL, and present key metrics through a Power BI dashboard.

The analysis covers customer demographics, purchase amounts, product categories, subscription status, shipping preferences, discounts, and purchasing frequency.

## Tech Stack

- **Python:** Data preparation and feature engineering
- **Pandas:** Data manipulation and missing-value handling
- **Jupyter Notebook:** Interactive data analysis
- **PostgreSQL:** Relational database storage
- **SQL:** Business queries and aggregations
- **Power BI:** Dashboard development and data visualisation

## Project Workflow

### 1. Data Cleaning and Preparation — Python

Performed data preparation using Pandas:

- Inspected the dataset structure, data types, descriptive statistics, and missing values.
- Handled missing review ratings using the median rating within each product category.
- Standardised column names to lowercase and replaced spaces with underscores.
- Renamed `purchase_amount_(usd)` to `purchase_amount`.
- Created an `age_group` column using quartile-based age segmentation.
- Converted purchase-frequency categories into approximate day intervals using a mapping dictionary.
- Compared `discount_applied` and `promo_code_used` and removed the latter after checking whether their values matched.

### 2. Database Integration — PostgreSQL

- Connected Python to PostgreSQL using SQLAlchemy and the PostgreSQL driver.
- Loaded the prepared DataFrame into a PostgreSQL table named `customer`.
- Used the database table as the source for the SQL business analysis.

### 3. SQL Business Analysis

Developed 10 SQL queries to investigate customer behaviour and purchasing patterns using aggregations, filtering, subqueries, `CASE` expressions, Common Table Expressions (CTEs), and window functions.

### 4. Dashboard Development — Power BI

Created a Customer Behaviour Dashboard containing KPI cards, category comparisons, customer breakdowns, and interactive filters.

## SQL Business Questions

The SQL script addresses the following questions:

1. What is the total purchase revenue generated by male and female customers?
2. Which customers applied a discount and spent at least the average purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express shipping?
5. How do subscriber and non-subscriber customer counts, average spending, and total revenue compare?
6. Which five products have the highest discount-application rates?
7. How many customers belong to the New, Returning, and Loyal segments based on previous purchases?
8. What are the three most-purchased products within each category?
9. How many repeat buyers with more than five previous purchases fall into each subscription-status group?
10. What is the total purchase revenue contributed by each age group?

## Getting Started

### Prerequisites

- Python 3
- Jupyter Notebook
- PostgreSQL
- Power BI Desktop
- The customer shopping behaviour CSV dataset

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/customer-behaviour-analysis.git
cd customer-behaviour-analysis
```

### 2. Install Python Dependencies

```bash
pip install pandas sqlalchemy psycopg2-binary jupyter
```

### 3. Prepare the Dataset

Place the CSV dataset in your local project directory and update the file path in the notebook. The current notebook uses a local Windows file path, so this needs to be changed when running it on another machine.

### 4. Configure PostgreSQL

Create a PostgreSQL database named `customer_behaviour` and configure valid connection credentials.

Before publishing, replace hardcoded database credentials in the notebook with environment variables. Never commit actual passwords to GitHub.

### 5. Run the Notebook

Open the Jupyter Notebook:

```bash
jupyter notebook
```

Run `customer_shopping_behaviour_analysis.ipynb` sequentially to prepare the data and load it into the PostgreSQL `customer` table.

### 6. Execute the SQL Queries

Open `customer_behavior_sql_queries.sql` in pgAdmin or another PostgreSQL client. Connect to the database containing the `customer` table and execute the queries.

### 7. Open the Power BI Dashboard

Open `customer_behaviour_dashboard.pbix` in Power BI Desktop. Configure the data source if necessary and refresh the report to view the dashboard.

## Notes and Limitations

- The age groups are created using quartiles, so the resulting boundaries depend on the dataset.
- Purchase-frequency day intervals are assigned using predefined mappings.
- The notebook removes `promo_code_used` after checking its equality with `discount_applied`. Confirm that these fields are equivalent for the full dataset before relying on this transformation.
- The SQL segmentation classifies one previous purchase as `New`, two to ten as `Returning`, and all other values as `Loyal`. This means zero previous purchases are also classified as `Loyal` in the current query.
- The top-three-products query uses `ROW_NUMBER()`, so it returns at most three products per category.
- Numerical findings and business recommendations should be added only after validating the query results.
